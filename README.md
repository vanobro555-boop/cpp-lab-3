### 📂 Задания и реализация

#### Задание 1: Базовая иерархия (Абстрактные классы и полиморфизм)
- **Условие:** Спроектировать систему "Зоопарк". Создать абстрактный класс `Animal` и 3 подкласса (`Lion`, `Elephant`, `Penguin`). Продемонстрировать полиморфные вызовы и разницу между ранним и поздним связыванием.
- **Код:** [lab3task1OOP](./lab3task1OOP) *(замени на имя своей папки)*
- **Ключевые особенности:**
  - **Абстрактный класс:** `Animal` содержит чистые виртуальные методы (`= 0`), что делает невозможным создание его экземпляра.
  - **Позднее связывание:** Вызов виртуальных методов (`makeTheSound()`) через указатель базового класса `Animal*` определяется во время выполнения программы.
  - **Раннее связывание:** Вызов невиртуального метода `sleep()` определяется на этапе компиляции.
  - **Безопасное приведение типов:** Использование `dynamic_cast` для вызова специфических методов подклассов (например, `LionAction()`).

#### Задание 2: Расширение системы (Принцип Open/Closed)
- **Условие:** Добавить новый тип (Дельфин) в систему, не изменяя существующий код базового класса и логики `main()`.
- **Код:** [lab3task2OOP](./lab3task2OOP)
- **Ключевые особенности:**
  - **Принцип Open/Closed (OCP):** Система открыта для расширения (добавление класса `Dolphin`), но закрыта для изменения (код `Animal`, `Lion` и цикл в `main` остался нетронутым).
  - **Масштабируемость:** Для добавления новых видов животных достаточно просто создать новый класс-наследник и добавить его в массив.

#### Задание 3: Интерфейсы и множественная реализация
- **Условие:** Реализовать независимые возможности через интерфейсы: `ITrainable` (выполнить трюк), `IFeedable` (получить порцию), `IMoveable` (переместиться). Показать полиморфизм через ссылки на интерфейсы и разрешить конфликт имен методов.
- **Код:** [lab3task3OOP](./lab3task3OOP)
- **Ключевые особенности:**
  - **Множественное наследование интерфейсов:** Класс `Penguin` реализует все три интерфейса одновременно.
  - **Разрешение конфликтов (Name Hiding/Conflict):** Интерфейсы `ITrainable` и `IMoveable` имеют одинаковый метод `showYourself()`. В классе `Penguin` конфликт разрешен через явное указание области видимости: `IMoveable::showYourself()`.
  - **Полиморфизм на уровне интерфейсов:** Создание массивов `IFeedable*` и `IMoveable*`, куда помещаются разные животные, обладающие нужным поведением.
